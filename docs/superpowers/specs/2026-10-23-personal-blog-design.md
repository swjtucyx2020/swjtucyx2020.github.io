# 「慢慢记」个人博客设计

日期：2026-10-23

## 目标与已确认的需求

为生活记录与个人随笔搭建中文个人博客。暂用名称「慢慢记」，采用米白与深绿色风格，覆盖首页、文章页、分类归档和关于页。手机与电脑均可阅读。用户已同意使用 GitHub Pages 免费网址，并公开博客源码与已发布文章。

成功标准：得到可阅读、可持续发布文章的博客及中文维护说明；不依赖付费主题、付费字体、付费图库或付费服务。上线必须以实际成功部署为准。

## 页面与交互

- 首页：品牌导航、简短欢迎语、精选文章、最新文章列表、分类入口、页脚。
- 文章：标题、日期、分类、阅读时间、正文、返回文章列表；长文自动生成目录。
- 归档：按年份展示文章，支持分类筛选与标题/摘要搜索，显示无结果状态。
- 关于：博客理念和可编辑的自我介绍，不捏造作者的身份、地址、社交账号或联系方式。
- 404：说明页面不存在并提供返回首页的入口。
- 移动导航、键盘焦点、跳过导航链接和减弱动画偏好均可用。

首批提供三篇明确标注的示例随笔，帮助用户体验文章排版；内容不是对用户真实经历的陈述。关于页说明名称、介绍和示例文章可以替换。

## 视觉方向

整体像一本安静的生活手账：温暖纸色背景、深绿墨色、细分隔线、宽松留白，正文使用本机中文字体，标题采用本机衬线字体。桌面文章阅读区保持合适行宽，移动端留出足够边距。装饰使用原创 CSS/SVG，不依赖远程字体或第三方图片加载。

## 实现与数据流

使用开源 Astro 的静态生成能力，文章保存在 `src/content/posts/*.md`，站点名称、介绍、作者称呼和网址集中在 `src/site.config.ts`。构建时校验内容字段并生成静态 HTML、RSS、站点地图和搜索资料。浏览器只为导航、筛选和搜索加载少量 JavaScript；正文无需 JavaScript 即可阅读。

文章字段：title、description、pubDate、category、tags、featured、draft。draft 为 true 的文章不出现在任何发布产物中；日期使用明确的年月日。文章 slug 来自文件名且不得重复。

不提供登录后台、评论服务、邮件订阅收集或数据库。后续通过编辑 Markdown 并提交到 GitHub 更新文章。

## 发布与免费资源

正式托管首选 GitHub Pages，使用账户下可用的新仓库；优先使用用户站点仓库 `swjtucyx2020.github.io`，若已有内容则不覆盖。GitHub Actions 负责构建和发布。配置兼容仓库子路径。

当前连接可识别 GitHub 账户，但尚未确认创建仓库及启用 Pages 的权限。现有连接不提供这两项写入操作，必要时通过已登录的浏览器完成；若遇到登录或账户授权要求，先完成全部本地实现和预览，再准确交代剩余操作。

采用平台免费子域名，不购买自定义域名。GitHub Pages 的免费条件及额度以官方文档为准，不承诺平台永久免费。

## 失败处理与验证

缺少必填文章字段时构建失败并指出源文件；草稿不会泄露到列表、RSS、搜索或站点地图。搜索为空时显示全部文章，无匹配时显示明确提示。

运行内容边界验证与生产构建；检查生成页面、内部链接、RSS 和站点地图。使用本地浏览器验证桌面与移动端排版、导航、搜索、筛选和文章阅读。部署后确认工作流结果或实际访问状态，再交付真实网址。
